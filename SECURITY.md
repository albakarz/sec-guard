# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `sec-guard` seriously. If you believe you have discovered a vulnerability, please do NOT create a public issue on GitHub.

Instead, please report security issues confidentially via **GitHub Private Vulnerability Reporting**:

👉 **[Report a Security Vulnerability](https://github.com/Albakarz/sec-guard/security/advisories/new)**

*(On the repository page, navigate to the **Security** tab &rarr; **Advisories** &rarr; **Report a vulnerability**)*

### What to Include:
- Description of the vulnerability and attack vector
- Reproduction steps or proof-of-concept (PoC)
- Potential impact and affected versions
- Any proposed mitigations or patches

### Response Timeline:
- **Acknowledgment:** Within 24-48 hours
- **Assessment & Triage:** Within 5 business days
- **Fix & Advisory Release:** Coordinated disclosure once resolved
